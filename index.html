Données · Apprentissage automatique

Détection de fraude

Python · Scikit-learn · Classification
Contexte : [individuel ou équipe] · Période : [à préciser]

Le besoin

Étudier comment des modèles d’apprentissage automatique peuvent repérer des transactions frauduleuses dans un ensemble de données où les fraudes sont peu nombreuses.

La démarche du projet

  1. Explorer les données et observer la répartition des transactions normales et frauduleuses.
  2. Préparer les variables pour les modèles.
  3. Traiter le déséquilibre des classes dans les données d’entraînement.
  4. Comparer plusieurs algorithmes de classification.
  5. Examiner la précision, le rappel, le score F1 et les matrices de confusion.

Les modèles étudiés

  • KNN
  • Régression logistique
  • Arbre de décision
  • Forêt aléatoire
  • Gradient Boosting
